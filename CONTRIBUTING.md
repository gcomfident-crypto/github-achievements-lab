# Contributing

This repository is a contained workspace for learning GitHub collaboration workflows.

## Principles

- Keep experiments inside this repository.
- Use an issue to explain why a change is needed.
- Submit changes through a focused pull request.
- Avoid unsolicited activity in other projects.

## Workflow

1. Open an issue with a concrete goal.
2. Create a focused branch.
3. Submit and verify a pull request.
4. Close the issue through the merged change.
